# Public Roadmap

Reconciled against source and executed tests on 24 October 2026. Items are intentions, not paid guarantees.

## Foundation and playable alpha

- [x] Flutter Android scaffold, architecture, original branding, community files, and CI
- [x] Shared deterministic puzzle contract and eight playable modules
- [x] Home, catalog, daily, gameplay, results, favorites, and Continue flows
- [x] Local settings, progress, hints, undo/redo, and integrity-checked backups
- [x] English and Hindi, responsive layouts, and accessibility preferences
- [x] Basic campaign selector, achievements, statistics, themes, and creator editor
- [x] Puzzle Path rename, current creator contacts, and optional external support links
- [x] Save ordering, completion snapshot, session resume, and daily-streak regression fixes

## Release hardening

- [x] Strict formatter/analyzer and 55 local tests pass
- [x] Protected upload-key configuration and required-signing guard
- [ ] Refreshed Android artifacts reviewed and signer state recorded
- [ ] Signed AAB verified against the maintainer's upload certificate
- [ ] Device integration, TalkBack, large text, orientation, lifecycle, and profile performance gates
- [ ] Store assets, hosted privacy policy, listing/forms, and legal review
- [ ] GitHub PR stack reviewed and merged
