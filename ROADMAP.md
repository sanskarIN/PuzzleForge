# Public Roadmap

Roadmap items are intentions, not promises or paid guarantees. Maintainers may reorder them based on quality, accessibility, security, and contributor capacity.

## 0.1 — Foundation

- [x] Flutter Android scaffold
- [x] Repository, architecture, legal, branding, and CI foundation
- [ ] Shared deterministic puzzle engine
- [ ] First playable puzzle set

## 0.2 — Playable alpha

- [ ] Home, catalog, daily challenge, gameplay, results, favorites, and continue flows
- [ ] Local persistence, undo/redo, hints, and progress
- [ ] English and Hindi

## 0.3 — Feature beta

- [ ] Campaign, achievements, statistics, themes, deep settings, and creator tools
- [ ] Accessibility, responsive layout, backup validation, and hardening

## 1.0 — Release candidate

- [ ] All automated gates green
- [ ] Physical-device and Play pre-launch checks completed
- [ ] Legal templates reviewed for the intended release jurisdiction
- [ ] Signed AAB produced outside source control

## Later

- Additional original puzzle modules and authored campaigns
- Optional privacy-reviewed cloud sync and classroom services
- Optional fair cosmetic or content packs through platform-compliant billing
