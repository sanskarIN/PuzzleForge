# Android, Kotlin, and Gradle

Android is the mandatory platform. The host uses Kotlin and Gradle files produced for the pinned Flutter stable release, Java 17 compatibility, app ID `com.sanskarin.puzzle_forge`, adaptive icons, native splash, explicit backup rules, and a restrictive network-security configuration.

Use Android Studio and `flutter doctor -v` for SDK diagnostics. Do not hand-upgrade Gradle, Kotlin, AGP, compile SDK, or NDK in isolation; use Flutter compatibility guidance and a full build matrix. Kotlin is Apache-2.0; Gradle is Apache-2.0.
