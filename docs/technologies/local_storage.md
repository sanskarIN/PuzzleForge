# Local Storage Packages

SharedPreferences stores compact, versioned JSON envelopes and primitive boot preferences. It is not a secret store and must not contain credentials. Large authored content or history may migrate to a transactional database in a future schema after measured need.

URL Launcher handles only fixed allowlisted HTTPS and mailto destinations after player activation. Both packages are selected for maintained Flutter platform support, minimal scope, and permissive licenses; resolved versions and licenses are release-reviewed from `pubspec.lock`.
