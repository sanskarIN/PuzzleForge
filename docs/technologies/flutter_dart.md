# Flutter and Dart

Flutter 3.44.7 stable with Dart 3.12.2 is the reference baseline; the package constraint supports newer compatible stable Flutter releases before Flutter 4. Install Flutter, accept Android licenses, install JDK 17 and an Android SDK, then run `flutter doctor -v` and repository checks. Domain code remains Flutter-independent where possible.

Debug UI with Flutter DevTools; reproduce gameplay with the recorded module ID, version, difficulty, and seed. Upgrade only on a dedicated branch: read Flutter breaking changes, update lockfiles, regenerate Android scaffolding selectively, run all tests/builds, and compare accessibility and performance.
