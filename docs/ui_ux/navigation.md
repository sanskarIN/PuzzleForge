# Navigation

The primary path is Splash → Home → Catalog or Daily → Difficulty → Gameplay → Result. Gameplay owns Pause and Hint sheets so a back action cannot accidentally create duplicate sessions.

Home exposes Continue only when a valid save exists. Secondary destinations—Campaign, Favorites, Statistics, Achievements, Themes, Guide, Support, About, and Settings—use a responsive menu. Destructive actions always require confirmation. Deep links are not enabled in the first release, avoiding unvalidated external route input.
