# Design System

PuzzleForge uses Material 3 foundations with a compact custom token layer.

- Primary: indigo `#4F46E5`; dark primary `#A5B4FC`
- Secondary: teal `#0F766E`; dark secondary `#5EEAD4`
- Accent: ember `#F97316`
- Error: theme-derived Material error roles
- Spacing: 4, 8, 12, 16, 24, 32, and 48 logical pixels
- Corners: 12 for controls, 20 for cards, 28 for hero surfaces
- Minimum interactive target: 48 × 48 logical pixels

Every semantic color has a non-color companion such as text, shape, pattern, icon, or border. Components use theme color roles rather than literal background/foreground combinations. Player settings can strengthen borders and contrast.
