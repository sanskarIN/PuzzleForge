# Accessibility

- All controls have semantic labels, roles, states, and logical traversal order.
- Tiles use symbols, numbers, shapes, and borders in addition to color.
- Board gestures have button or keyboard equivalents.
- Text follows system scaling and responsive containers avoid fixed-height copy.
- High contrast increases borders and uses contrast-checked roles.
- Reduced motion removes decorative travel, particles, and scale transitions.
- Haptics and sound are optional; neither carries unique information.
- Timers do not prevent completion and pause when the app is paused.
- Hints remain earnable and no accessibility setting consumes currency.

Manual TalkBack, large-font, switch-access, and color-vision checks remain required on representative devices before 1.0.
