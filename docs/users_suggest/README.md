# User Suggestions

Open a GitHub feature request describing the player problem, proposed experience, accessibility impact, and alternatives. Suggestions are triaged for fit, licensing, safety, fairness, maintainability, and evidence of demand. Submission does not transfer ownership of unrelated materials, guarantee implementation, or create payment/support priority.

Do not attach copyrighted puzzle books, private information, credentials, or paid assets. Security issues must be emailed privately according to `SECURITY.md`.
