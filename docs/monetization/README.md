# Ethical Monetization

Puzzle Path's source release contains no billing or advertising SDK. Support is optional through external Buy Me a Coffee, Razorpay, and PayPal links. The game does not collect payment details or confirm donations. Core mechanics, accessibility, daily puzzles, and earned hints remain usable without payment.

Any future commercial feature is separately gated behind store compliance, privacy review, server validation where necessary, transparent pricing, restore behavior, family protections, and updated notices.
