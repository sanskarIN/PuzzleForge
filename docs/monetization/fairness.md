# Monetization Fairness

- Core puzzle rules are complete without payment.
- Difficulty is never manipulated to force a purchase.
- Accessibility features are free.
- Paid content never changes a competitive outcome.
- Prices, recurring terms, and restore behavior are clear before confirmation.
- Ads, if ever added, cannot interrupt a move or obscure a board.
- Rewarded ads require explicit consent and a useful non-paid path.
- Children and family use require platform protections and age-appropriate design.
