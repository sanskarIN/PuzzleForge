# Settings

Settings are grouped into General, Appearance, Gameplay, Controls, Sound & Haptics, Accessibility, Language, Notifications, Data & Storage, Privacy, Security, Performance, Battery Saver, Support, About, Legal, and Developer Options.

The first offline release stores settings locally and does not request notification permission until a real notification feature is enabled. Developer Options unlock after seven version taps and expose deterministic seeds, state inspection, feature flags, localization inspection, performance overlays, test-data generation, and safe resets—never secrets or paid entitlements.
