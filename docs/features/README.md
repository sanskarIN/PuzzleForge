# Features

Implemented features and release evidence are tracked in `PROJECT_STATUS.md`. PuzzleForge's first release scope is offline play: deterministic puzzle modules, daily challenges, endless seeds, campaign milestones, favorites, continue, local history, achievements, statistics, themes, settings, backups, and a safe creator editor.

Future online, advertising, purchase, and cloud features are disabled by design until their own privacy, security, billing, and server-authority reviews are complete.
