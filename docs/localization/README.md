# Localization

PuzzleForge ships English (`en`) and Hindi (`hi`) source catalogs and an English-derived expanded pseudolocale (`en-XA`) for developer layout checks. Runtime locale changes rebuild the app without reinstalling.

The catalog supports named arguments, singular/other plural forms, locale-aware dates and numbers, English fallback, and automated key parity. Material components provide locale-aware layout direction; custom boards use logical alignment and do not encode left/right padding in translated content.

Hindi is a developer-prepared translation and is not claimed to have professional linguistic review. Release contributors should review gameplay terminology, accessible descriptions, and legal text with qualified native speakers.
