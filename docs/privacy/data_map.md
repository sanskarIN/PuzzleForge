# Data Map

| Data | Location | Purpose | Leaves device? |
|---|---|---|---|
| Settings and accessibility preferences | App preferences | Personalization | No |
| Active puzzle and history | App preferences | Continue, records, replay | No |
| XP, achievements, streaks, hints | App preferences | Local progression | No |
| Favorites and authored levels | App preferences | Personal library/editor | No |
| Explicit backup export | User-selected destination | Portability | Only where the user sends it |
| Support/GitHub URL | External browser after tap | Visit external page | Destination receives normal browser traffic |
| Email address/action | External mail client after tap | Contact support | Only if the user composes/sends mail |

No account identifier, advertising ID, location, contacts, camera, microphone, analytics event, or remote leaderboard payload is collected by the first release.
