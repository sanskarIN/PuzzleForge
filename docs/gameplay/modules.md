# Enabled Module Difficulty Rules

All modules use deterministic seeds and verify structural invariants before play.

| Module | Difficulty scaling | Solvability strategy |
|---|---|---|
| Sliding Tiles | 3×3 Beginner/Easy, 4×4 Medium/Hard, 5×5 Expert/Master; scramble length rises by 14 moves per rank | Generated only through legal moves from the goal; imported boards require valid permutation and parity |
| Number Merge | Goal rises from 128 to 4096 | Any generated opening is valid; deterministic LCG controls tile spawn; legal-direction detection prevents no-op moves |
| Light Grid | Board grows from 3×3 to 7×7 and seeded press count rises | Generated by applying presses to the solved board; remaining press vector is a constructive solution |
| Maze | Odd board grows from 7×7 to 17×17 | Randomized depth-first carving creates a connected perfect maze; BFS verifies reachability and supplies hints |
| Sudoku | Clues decrease from 50 to 23 | A valid transformed base solution is stored; givens are consistent and every hint references the solution. Unique-solution generation is a post-beta enhancement. |
| Memory Match | Pair count grows from 3 to 12 | Every symbol is generated exactly twice and the verifier rejects invalid pairing |
| Color Sort | Three to five colors; scramble steps rise with rank | Constructed from solved tubes with a recorded reversible one-token action sequence; counts and solved state are verified |
| Number Sequence | Arithmetic, previous-two sum, then quadratic patterns | Answer is calculated before distractors; the verifier requires the answer in the choice set |

Difficulty labels reflect board size, clue count, target, pair count, or rule complexity rather than arbitrary presentation. Personal records are separated by module and difficulty.
